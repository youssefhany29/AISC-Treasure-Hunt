# Organizer guide — contains solutions

Expected play time: 3–5 minutes. Medium difficulty. Participants start at the cafe and solve the game in English.

## Solutions

- Receipt: **▲ = 8**
- Under the coffee cup: **● = 3**
- Folded napkin: **■ = 6**
- Reverse of coaster: **★ = 1**
- Lock order: **■ ▲ ★ ●**; unlock sequence **6813**.
- Blueprint: **entrance → indoor court → scoreboard and spectator stands**. Select two fragments to swap. Pieces are crops from `assets/images/blueprint/continuous.svg`, with real continuous lines across seams.
- Final answer: **Door D — Indoor Sports Hall**.
- Mission Complete reveals **SPOR SALONU**. No location address or unverified map is invented.

## Event preparation

1. Verify the live HTTPS site from a logged-out browser.
2. Open Case settings, expand the organizer reset, and deliberately reset for a fresh device test.
3. Test the printed QR on physical iPhone/Android devices with the event venue's connectivity.
4. Check sound is optional, hints work, and all text is readable outdoors/under venue lighting.
5. Finish the mission; reload to confirm the success screen remains available to show event volunteers.
6. Keep the next-checkpoint link hidden unless an organizer has verified the exact HTTPS URL.

There is no time penalty, attempt limit, personal-data collection, account requirement, or music. Do not add a countdown that can cause an event participant to fail.
